# luktor.ca

The public page of Luktor Labs, served by GitHub Pages from `main`.

- `index.html` is the page; the dovetail drawing inside it is generated:
  `python3 tools/build.py` (no dependencies).
- `fonts/`: Alegreya and Alegreya Sans, under the SIL Open Font License
  (`fonts/OFL.txt`, `fonts/OFL-sans.txt`).
- The site loads nothing from anyone else and sets no cookies. Keep it so.
- It says what the user sees, never how anything is built.
